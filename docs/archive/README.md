# Archiv dokumentace

Tato složka obsahuje historické acceptance reporty, benchmarky a měřicí výstupy dokončených optimalizačních bloků. Nejde o aktuální specifikaci projektu.

Aktuální dokumenty jsou:

- `README.md` v kořeni – uživatelské chování a provoz,
- `docs/PROJEKT.md` – současná technická architektura a invarianty,
- `docs/PLAN.md` – otevřené úkoly, nápady a stav rozpracovaných bloků,
- `docs/BLOK3-TEREN.md` – provozní dokumentace verzovaného terénního datasetu.

Historické soubory se ponechávají kvůli dohledatelnosti měření a rozhodnutí. Jejich tvrzení o tehdejším stavu nemají přednost před současným kódem a aktuální dokumentací.
